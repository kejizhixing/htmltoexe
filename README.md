## 1. 软件简介

**HtmlToExe 打包器**是一款可以将任何网页（在线网址或本地 HTML 文件夹）打包成独立 Windows 可执行程序（EXE）的工具。打包后的程序基于 Microsoft Edge WebView2 技术渲染网页，无需用户安装浏览器即可运行，适用于制作桌面应用、内部工具、演示程序等场景。

## 2. 主要功能

- **在线/本地双模式打包**  
  支持输入网址自动抓取网页内容，或选择本地包含 `index.html` 的文件夹进行打包。
- **自定义窗口行为**  
  可设置窗口宽高、是否允许最大化/最小化、置顶、系统托盘、居中启动、全屏启动等。
- **图标与标题滚动**  
  支持自定义 EXE 图标（ICO 格式），可设置标题栏滚动文字。
- **高级配置嵌入**  
  所有打包参数（窗口大小、功能开关、滚动文字等）均存储在 EXE 尾部，无需额外配置文件。
- **轻量化无依赖**  
  打包后的 EXE 仅依赖 Microsoft Edge WebView2 Runtime（Windows 10/11 通常已内置）。
- **数据持久化与隔离**  
  打包后的程序拥有独立的数据目录，登录状态、Cookies 等数据可持久保存，且不同程序互不干扰。

## 5. 快速开始

### 5.1 在线网址打包

1. 启动软件，默认选择“**在线网址**”模式。
2. 在网址输入框中输入目标网址，例如 `https://example.com`。
3. 点击“**开始打包**”。
4. 软件会自动抓取网页标题和图标，并生成默认应用名称。
5. 选择保存位置（默认输出到“打包输出”文件夹）。
6. 等待打包完成，即可获得独立 EXE 文件。

### 5.2 本地文件夹打包

1. 选择“**本地文件夹**”模式。
2. 点击“**浏览**”按钮，选择包含 `index.html` 或 `index.htm` 的本地文件夹。
3. 软件会自动检测入口文件和图标（若存在 `favicon.ico` 等）。
4. 点击“**开始打包**”。
5. 选择保存位置，等待完成。

## 6. 详细设置说明

### 6.1 应用名称

- 生成的 EXE 文件名及窗口标题。
- 在线模式下，若留空或使用默认值，会自动抓取网页标题。
- 本地模式下，若留空，默认使用文件夹名称。

### 6.2 窗口尺寸

- 设置打包后程序窗口的初始宽度和高度（像素）。
- 最小尺寸为 **320×240**，默认 **1024×768**。
- 用户可在运行后手动调整窗口大小（若允许）。

### 6.3 滚动文字

- 显示在标题栏的滚动文字，可用于展示公告或品牌信息。
- 留空则不滚动。

### 6.4 图标文件

- 支持 `.ico` 格式图标文件。
- 在线模式下，若留空会自动尝试下载网站 favicon。
- 本地模式下，若留空会自动检测目录下的 `favicon.ico`、`icon.ico` 等。
- 建议使用包含 16×16、32×32、48×48、256×256 等尺寸的 ICO 文件。

### 6.5 窗口功能选项

| 选项 | 说明 |
|------|------|
| **最大化** | 是否允许窗口最大化 |
| **最小化** | 是否允许窗口最小化 |
| **置顶** | 窗口是否始终保持在最前端 |
| **托盘** | 关闭窗口时是否最小化到系统托盘 |
| **居中** | 程序启动时窗口是否居中显示 |
| **全屏** | 程序启动时是否直接进入全屏模式 |

## 8. 数据目录与备份还原

打包后的程序运行时会创建一个独立的数据目录，用于保存登录状态、Cookies、本地存储等。

**数据保存位置：**

```
%APPDATA%\HtmlToExe\M\WebView2Data
```

示例路径：

```
C:\Users\用户名\AppData\Roaming\HtmlToExe\M\WebView2Data
```

**重要说明：**

1. 该目录存储了所有登录状态和网站数据，请勿随意删除，否则会丢失登录信息。
2. 若需重装系统或更换电脑，可以备份整个 `WebView2Data` 文件夹。在新电脑上安装相同名称的打包程序，并将备份文件夹覆盖到相同位置，即可恢复所有登录状态和网站数据，无需重新登录。
3. 若希望清除登录信息（例如公用电脑），只需删除该目录即可。下次启动程序将如同无痕浏览，所有登录信息将被清除。
4. 若无备份需求，则无需任何操作，程序默认会自动保存所有数据。

## 10. 常见问题

**Q: 程序启动后白屏？**  
A: 请检查网络连接（在线模式）或确认 `index.html` 路径正确（本地模式）。

**Q: 程序无法启动或闪退？**  
A: 请确认目标电脑已安装 Microsoft Edge WebView2 Runtime。

**Q: 图标显示不正确？**  
A: 请使用标准 ICO 格式图标文件，建议包含多种尺寸（16/32/48/256）。

**Q: 标题栏没有滚动文字？**  
A: 请在“滚动文字”输入框中填写内容，留空则不滚动。

**Q: 如何备份登录状态？**  
A: 将 `%APPDATA%\HtmlToExe\M\WebView2Data` 文件夹复制到安全位置即可。重装或换机后，将备份文件夹放回原路径即可恢复。

**Q: 打包后的程序提示缺少 WebView2 Runtime？**  
A: 请在目标电脑上安装 WebView2 Runtime，Windows 7 用户需安装专用版本。

**Q: 生成的 EXE 文件被杀毒软件误报？**  
A: 由于采用模板 PE 方式，部分杀软可能误报，请添加信任或使用正规签名证书。
