  HtmlToExe 打包器 v1.9.4 —「更多选项」全部功能使用说明
════════════════════════════════════════════════════════════

打开方式：主界面点「更多选项」按钮，窗口自动贴在主窗口右侧。
所有选项默认不勾选；勾选后对本工具打出的每一个 EXE 都生效。

────────────────────────────────────────
一、窗口外观区（前 5 项）
────────────────────────────────────────

【Region（区域）】
作用：只打包网页中的某一块固定区域——比如只要页面中间的一个表格/播放器，
      打包出的应用窗口里就只显示这一块，且完全不能滚动。
用法与验证（网址可以直接在预览窗内输入，无需先填主界面）：
  1. 更多选项里勾选「Region」→ 弹出 1200x850 预览窗（标题栏有应用图标）
  2. 在预览窗顶部网址框输入 http:// 或 https:// 开头的在线网址 → 点「预览」
     （或按回车）加载网页；主界面已有网址时会自动带入、直接加载
  3. 在网页上按住鼠标左键拖出一个矩形：**任意位置、任意方向**都能框
     ——从哪按下就从哪开始，往左拖/往右拖都行，框随鼠标实时走；
     页面内嵌的 iframe 视频/地图/嵌入内容也能直接框；可反复拖，以最后一次为准
  4. 点预览窗的「确定使用选区」→ 提示"已选定区域"，同时窗内网址自动
     同步回主界面地址栏并切换到在线模式（只在勾选区域时才同步）
  5. 回主界面点「开始打包」即可
  6. 运行打包的应用：窗口里只显示所选区域，按窗口比例自动缩放铺满，
     滚轮/方向键/触摸滑动全部无效（不滚动）
窗口调整：
  · 预览窗可以拖动四周边框自由调整大小，网页区域实时跟随布局，
    拉大窗口看得更全、框选更准；最小 800x500，屏幕放不下时自动收缩
改选/取消：
  · 想重新框选：取消勾选 Region 再重新勾选即可（网址会自动带入上次输入的）
  · 想恢复整页：直接取消勾选 Region
注意：
  · 仅对在线网址有效（窗内校验 http/https，输本地路径会提示）
  · 选区坐标是按预览时的网页版式记录的；目标网站日后改版，区域内容可能变化
  · 需要系统已安装 Microsoft Edge WebView2 Runtime（打包器与打包应用均依赖）

【无框】
作用：打包出的应用窗口无边框、无系统标题栏，网页铺满整个窗口。
用法：直接勾选，无需其他设置。
运行效果与验证：
  1. 鼠标移到窗口顶部边缘 → 浮现透明标题栏（最小化/最大化/关闭）
  2. 页面右侧滚动条自动隐藏（滚轮/方向键滚动完全正常）
  3. 网页内标题（h1~h6）字体变金黄色
  4. 窗口四角变圆角（Win11 系统平滑圆角；Win10 圆角裁剪）
  5. 窗口内拖动：按住顶部浮现的标题栏拖动
注意：与「窗口透明」同时勾选时，透明自动跳过（两者技术互斥）。

【固定】
作用：打包应用内网页不能上下滚动（适合工具类页面）。
验证：打开应用后滚轮无反应、页面无法拖动。
注意：内容超出屏幕的部分将无法看到，仅适合单屏内容的页面。

【摸鱼】
作用：空格键一键隐身——正在看视频/听音乐时老板来了，按一下空格：
  声音全部静音 + 窗口秒收到托盘 + 任务栏图标消失。
用法与验证：
  1. 运行打包的应用，正常播放任意视频
  2. 按空格 → 声音立即消失，窗口消失，托盘出现图标
  3. 托盘图标双击 → 窗口回来，声音恢复
  4. 在网页输入框里打字时按空格 = 正常输入空格，不会误触发
注意：只勾选「摸鱼」时才有此功能，其他任何功能不受影响。

【公告】
作用：应用启动时先弹公告窗口（可设标题/内容/倒计时秒数）。
用法：勾选后自动弹出设置框 → 填写 → 确定。
验证：打开打包的应用，启动即见公告，倒计时结束自动进入页面。

────────────────────────────────────────
二、运行行为区（6 项）
────────────────────────────────────────

【禁止多开】
作用：同一应用同时只能开一个，重复双击提示"程序已在运行"并置顶旧窗口。
验证：双开 EXE 测试。

【禁用右键】
作用：打包应用内网页右键菜单全部禁用。
验证：运行后按 F12 无反应（开发者工具无法打开）。

【F12 调试】
作用：保留开发者工具（默认勾不勾都不影响；勾选=允许按 F12 打开调试器）。
验证：勾选打包 → 运行 → 按 F12 弹出 DevTools 窗口。

【关闭到托盘】
作用：点应用右上角 X 不退出，收起到托盘；托盘右键可退出。
验证：点 X → 窗口消失但托盘图标在 → 右键托盘 → 退出。

【高 DPI】
作用：4K/缩放屏幕上窗口与文字清晰不模糊（默认建议勾选）。
验证：在 150%/200% 缩放的屏幕上打开应用，文字边缘清晰。

【禁止拖拽】
作用：不能向打包应用窗口拖入文件（防止误操作打开本地文件）。
验证：拖一个文件到窗口上，无任何反应。

────────────────────────────────────────
三、功能扩展区（12 项，v1.9.3/1.9.4 新增）
────────────────────────────────────────

◆ 开机自启
作用：打包的应用随 Windows 开机自动启动。
验证：勾选打包 → 运行一次该应用 → 打开任务管理器「启动」页，
      可见该应用（注册表 Run 键，键名 H2XApp_<应用文件名>）。
取消方法：取消勾选后重新打包 → 运行一次新 EXE → 自启项自动移除。

◆ 位置记忆
作用：应用记住上次关闭时的窗口位置和大小，下次打开还原。
验证：勾选打包 → 运行 → 拖动窗口到别处 → 关闭 → 再开 → 回到上次位置。
重置方法：删除 EXE 同目录下的 .pos 文件。

◆ 窗口透明
作用：整个窗口 85% 不透明度（半透明效果）。
验证：勾选打包 → 运行 → 窗口呈半透明，能透出后面的桌面。
注意：与「无框」同时勾选时自动跳过（技术互斥，保护无框标题栏渲染）。

◆ 页面缩放
作用：像浏览器一样 Ctrl+滚轮 缩放页面。
验证：勾选打包 → 运行 → 按住 Ctrl 滚动滚轮 → 页面放大/缩小
     （范围 25%~300%）。不按 Ctrl 滚轮 = 正常滚动页面。

◆ 外链转浏览器
作用：网页里点开的"新窗口"链接改用系统默认浏览器打开，不占应用窗口。
验证：勾选打包一个带外链的网站 → 点 target=_blank 的链接 →
     系统浏览器打开该链接，应用窗口保持原页面。
规则：配置了域名白名单 → 白名单外跳浏览器；未配置 → 除打包主页外全部跳。

◆ 下载管理
作用：网页里触发下载时弹"另存为"对话框，自选目录和文件名。
验证：勾选打包 → 打开任意带下载按钮的页面 → 点下载 → 弹出保存对话框。
不勾选时：WebView2 原生下载条（页面底部），行为不变。

◆ 深色跟随
作用：Windows 处于深色模式时，网页自动请求深色渲染（站点支持则变暗）。
验证：Windows 设为深色 → 勾选打包 → 运行 → 支持深色的站点自动变暗色。
浅色模式下勾选无任何变化。

◆ 静音启动
作用：应用一启动就全局静音（所有声音）。
验证：勾选打包一个视频站 → 打开 → 播放视频 → 无声。
解除方法（v1.9.4 新增）：托盘图标右键 → 「取消静音」→ 声音恢复。
      再点「静音」可再次静音，随时切换。

◆ 老板键
作用：全局热键 Ctrl+Alt+H，任何界面下按一下 → 应用窗口立即隐藏/显示。
验证：勾选打包 → 运行 → 切到别的程序 → 按 Ctrl+Alt+H → 窗口消失
     → 再按 → 窗口回来。与托盘功能兼容（隐藏后托盘图标仍在）。

◆ Ctrl+F 查找
作用：页面内查找文字。
验证：勾选打包 → 运行 → 按 Ctrl+F → 弹出输入框 → 输入文字回车
     → 页面跳到匹配处并高亮。找不到弹提示。
（焦点在网页内时有效——即正常使用状态即可触发）

◆ 更新检查
作用：应用启动 3 秒后静默检查 EXE 同目录的 update.json。
文件格式（自己创建，放 EXE 旁边）：
  {"version":"2.0","url":"https://你的下载页"}
验证：打包时在「版本设置」里填 fileVersion 为 1.0 → 打包 →
     在 EXE 旁建 update.json 写 version 2.0 → 运行 → 弹"发现新版本"提示。
     没有该文件 = 完全不打扰。

◆ 代理支持
作用：把 Windows 系统代理设置自动传给打包应用（内网环境用）。
验证：Windows 设置里配置代理 → 勾选打包 → 运行 → 应用走系统代理。
系统没开代理时勾选 = 无任何变化（自动跳过）。

────────────────────────────────────────
四、常见组合推荐
────────────────────────────────────────
· 视频站后台挂机：摸鱼 + 静音启动 + 关闭到托盘
· 内网工具分发：代理支持 + 位置记忆 + 禁止右键
· 对外分发的产品：单文件模式 + 公告 + 更新检查 + 禁止多开
· 极简皮肤：无框 + 页面缩放
· 只看网页某一块：Region（区域）+ 禁止多开
